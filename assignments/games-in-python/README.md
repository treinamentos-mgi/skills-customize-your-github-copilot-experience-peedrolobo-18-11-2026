
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python no qual o jogador adivinha uma palavra oculta antes de esgotar as tentativas. Pratique manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição

Implemente um jogo interativo que escolha uma palavra de uma lista predefinida e permita ao jogador adivinhar suas letras. Mostre o progresso da palavra e encerre a partida quando ela for descoberta ou quando não restarem tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar as letras descobertas e os espaços ainda ocultos (por exemplo, `_ _ _`).
- Registrar e exibir quantas tentativas incorretas ainda restam.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas incorretas.
- Exibir uma mensagem indicando vitória ou derrota.
